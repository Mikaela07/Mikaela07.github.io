二、数据库操作

提示：必须先 USE 库名（或用 -D 指定），建表才会建在这个库里。

三、建表 CREATE TABLE

1. 字段规则

类型 说明
VARCHAR(n) 字符串，n 是最大字符长度
INT 整数，上限约 21 亿，海量数据用 BIGINT
datetime 时间类型，不写长度
  • NOT NULL：字段不能为空，不写则允许 null
  • AUTO_INCREMENT：主键自增，从 1 开始
  • PRIMARY KEY：主键，非空且唯一，用来唯一标识一行数据

2. 末尾配置

  • ENGINE=InnoDB：MySQL 默认存储引擎
  • DEFAULT CHARSET=utf8：字符编码

3. 符号规则

规则 说明
全部英文符号 ❌ 中文逗号、中文括号会报错
反引号 ` 包裹表名 / 字段名 和单引号 ' 区分，编辑器高亮的关键字用作名称时必须套反引号
字段间逗号分隔 最后一个字段后不加逗号
语句末尾 ; 漏写会卡住

四、删表 DROP TABLE

  • IF EXISTS：表存在才删，不存在不报错
  • 删除后表和数据全部清除，不可逆，谨慎操作 ⚠

七、易错点汇总

易错点 正确做法
SHOW DATABASES 忘加 S ✅ 带 S，CREATE DATABASE 不带 S
忘记 USE 或 -D ✅ 先选库再建表，否则表建错库
漏写 ; ✅ 每条语句末尾必须有分号
中文符号 ✅ 全部用英文符号
建表最后字段多加逗号 ✅ 最后一个字段后不加逗号
字符串用双引号或反引号 ✅ 字符串值用单引号包裹
NOT NULL 字段没给值 ✅ 必须给值，否则插入报错
DROP 操作不可逆 ⚠ 谨慎执行，删了就没了

3. WHERE 条件过滤

WHERE 作用：限定查询条件，类似编程语言的 if，只取出条件结果为 true 的数据。

语法：

condition 代表判断条件。

示例：查询胜率超过 50% 的射手英雄

4. WHERE 常用比较运算符

运算符 含义 示例
= 等于 name = '张三'
!= 或 <> 不等于 age != 18
> 大于 win_rate > 0.5
< 小于 age < 20
>= 大于等于 score >= 60
<= 小于等于 price <= 100

九、LIMIT 限制返回行数

LIMIT 用来限定返回多少行数据，常用于分页。数据库行号从 0 开始计数。

1. 写法 1：LIMIT n 查询前 n 行

等价写法：SELECT * FROM timi_adc LIMIT 0, 5;

含义：取第 0~5 行，一共 5 条记录。

2. 写法 2：LIMIT offset, count 查询第 x-y 行

  • 第一个参数 offset：偏移量，从 0 开始，代表跳过多少行
  • 第二个参数 count：本次一共查询多少条记录

含义：跳过 5 行，从第 6 行开始，一共查询 6 条记录（查询第 6-11 行）。

含义：查询表第 5 行的数据。

3. LIMIT 和 WHERE 联合使用

提示：LIMIT 必须写在 WHERE 的后面。

示例：查询 timi_adc 表登场率大于 10% 的前 5 条数据

十、ORDER BY 排序

ORDER BY 用于对查询结果做排序。

1. 默认升序（ASC，默认可以省略不写）

数据类型 排序规则
int / double 从小到大
varchar 字符串 A → Z 字母顺序
datetime 时间 过去 → 现在

2. DESC 降序（逆序）

DESC：从大到小逆序排列。

3. 和 LIMIT 联合使用

提示：先排序，再 LIMIT，ORDER BY 写在 LIMIT 前面。

示例：查询胜率最高的 3 个射手

4. 语句书写顺序

顺序 关键字 说明
1 SELECT 查什么字段
2 FROM 从哪张表查
3 WHERE 条件过滤
4 ORDER BY 排序
5 LIMIT 限制行数

⚠ 注意：顺序不能乱，WHERE → ORDER BY → LIMIT 是固定顺序。
