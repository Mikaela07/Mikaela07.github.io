JavaScript总结

一、JS 代码引入 HTML 的两种方式

1. 内嵌式（写在 HTML 内部）

  • 使用 <script></script> 标签包裹 JS 代码
  • 规范写在 <body> 标签末尾
  • 旧写法：<script type="text/javascript" charset="utf-8">
  • 现代浏览器可省略全部属性，直接写 <script>
  • 注意：仅 HTML 中需要 script 标签，独立 .js 外部文件不能写 script 标签

2. 外部引入式（推荐，代码分离）

  • JS 代码单独存为 .js 文件
  • 通过带 src 属性的 script 标签引入

优势：HTML、JS 代码分离，项目易维护。

三、字符串相关语法

1. 普通字符串拼接

使用 + 加号拼接字符串与变量，写法繁琐。

2. 模版字符串（反引号 ` 包裹，推荐）

标识：反引号 ` 替代单 / 双引号

变量插入：占位符 ${变量名}，无需加号拼接

支持原生换行：普通字符串换行必须加转义符 \n

`` 模版字符串内输出反引号
\n 普通字符串换行

4. 字符串方法 str

方法 说明
str.length 只读属性，返回字符总长度
str.indexOf(sub) 查找子串起始下标，找不到返回 -1
str.trim() 仅清除首尾空格，中间空格不动
str.substring(s, e) 截取 [起始s, 结束e)，不含 e 下标字符
str.substr(s, len) 从 s 下标开始，截取指定长度 len 的字符
str.split(pattern) 按分隔符切割，返回新数组

易错区分：

  • substring(起始，终止下标) vs substr(起始，截取长度)

四、变量声明 let / const

1. let 规则

  • 可只声明不赋值，默认值为 undefined
  • 同一作用域禁止重复声明同名变量，会报语法错误
  • 声明后支持多次重新赋值

2. const 规则

  • 声明时必须同步赋予初始值，缺省值直接报错
  • 仅能赋值一次，后续重新赋值会报错
  • 同作用域不可重复声明同名变量

let、const 对比

特性 let const
声明时赋值 可选 必须
重新赋值 允许 禁止
重复声明 禁止 禁止

五、函数声明方式

1. 两种函数声明

函数声明（具名函数）

  • 格式：function 函数名() { 函数体 }
  • 组成四要素：function 关键字、函数名、()、{}
  • 结尾无需分号
  • 调用：函数名()

函数表达式（匿名函数赋值给变量）

  • 格式：let 变量名 = function() { 函数体 };
  • function 后无函数名，整体是表达式
  • 末尾必须加分号 ;
  • ES6 可简写为箭头函数：let 变量名 = () => {};
  • 调用：变量名()

2. 核心区别（提升 + 分号）

变量提升

类型 提升特性 说明
函数声明 有提升 调用可写在声明前面，JS 会把整个函数提前到代码顶部
函数表达式 无提升 必须先声明再调用，否则报错

分号规则

  • 函数声明：结尾 } 后不加分号
  • 函数表达式：末尾必须写 ;

3. 函数重复声明

同一函数名多次用 function 声明，后声明会覆盖前声明，最终执行最后定义的函数逻辑。

4. 参数匹配规则（JS 独有，和 Java 不同）

情况 处理方式
实参多于形参 多余实参直接忽略，程序不报错
实参少于形参 未传参的形参值为 undefined，不报错

（一）增（添加元素）

语法：splice(起始下标, 删除数量, 替换新元素)

（四）查（查找元素下标 indexOf()）

单个参数（常用）：indexOf(查找值)

  • 找到元素：返回对应下标
  • 未找到：返回 -1

两个参数：indexOf(查找值, 起始搜索下标)

  • 从第二个参数指定下标开始向后检索
  • 找不到返回 -1

（五）数组高阶方法 arr

方法 说明
arr.join(pattern) 把数组元素用分隔符拼接成字符串，和 split 互逆
arr.reverse() 直接修改原数组，倒序排列，无新数组返回
arr.sort(func) 自定义排序函数；纯字符串时间不能直接相减排序，要转 Date 时间戳
arr.map(fn) 遍历，每轮 return 值组装全新数组，不改动原数组；回调三参数：元素、下标、原数组
arr.forEach(fn) 纯遍历，无返回值，常用来修改原数组/对象；回调三参数同 map

易错区分：

  • map 有返回新数组，forEach 无返回
  • reverse、sort 会改动原数组

十二、Date 时间对象（高频易错重点）

1. 创建 Date 实例三种方式

方式 说明
new Date() 不传参 = 当前系统时间
new Date(年, 月, 日, 时, 分, 秒) 数字传参，月份 0~11（1月=0，12月=11）
new Date("2020-01-01") 时间字符串
new Date(毫秒数) 距离 1970-01-01 零点的毫秒时间戳

2. 静态方法

Date.parse(时间字符串)：将日期字符串转为毫秒时间戳

3. get 系列（取值，高频坑）

方法 说明 范围
getFullYear() 4位完整年份
getMonth() 月份 0~11，使用时必须+1
getDate() 当月几号 1~31（唯一从1开始的取值）
getDay() 星期 0(周日)~6(周六)，不是日期号
getHours() 小时 0~23
getMinutes() 分钟 0~59
getSeconds() 秒 0~59
getTime() 返回毫秒时间戳

易混淆：getDay() = 星期，getDate() = 当月几号

4. set 系列（修改原 Date 对象）

和 get 一一对应，无 setDay()（星期由日期自动算出，不可手动设置）

5. 时间运算与比较

操作 说明
Date 相减 两个 Date 对象直接相减，结果 = 毫秒差值
一天毫秒常量 24 * 60 * 60 * 1000
时间比较 直接用 > < 比较（底层对比毫秒时间戳）
toJSON() 输出标准 UTC 时间字符串 2020-01-03T09:44:18.220Z

6. 最容易忽略的大坑汇总

坑点 正确做法
getMonth() 返回 0-11 展示时必须+1；传参构造日期时也要减1
getDay() vs getDate() getDay()=星期，getDate()=当月几号
时间排序不能用 sort(a-b) 要转 new Date().getTime() 再相减
substr vs substring 参数含义完全不同，不能混用
对象遍历中新增属性 可直接 对象.新属性 = 值 自动新增

二十四、Object、JSON、Map 区分

1. JSON

跨语言文本交换格式，严格字符串

转换方法：

  • JSON.parse(json字符串)：JSON → JS 对象
  • JSON.stringify(JS对象)：JS 对象 → JSON 字符串

限制：仅支持基础类型，不能存函数、undefined

2. Object（普通对象）

  • 键只能是字符串 / Symbol
  • 键无序
  • 自带原型继承，存在原型属性干扰
  • 获取长度：Object.keys(obj).length

3. Map（键值集合）

  • 键支持任意类型（数字、对象、函数）
  • 插入顺序有序
  • 原生可遍历，直接用 map.size 获取键值对数量
  • 无原型继承冲突，无自带内置属性污染

对比表

特性 Object JSON Map
键类型 字符串/Symbol - 任意类型
键顺序 无序 - 有序
原型链 有 - 无
长度获取 Object.keys().length - map.size
存储内容 任意值 仅基础类型 任意值

二十五、Math 数学工具对象

静态属性/方法，无需 new

1. 常用数学常数（静态属性）

常量 说明
Math.PI 圆周率 π（约 3.14159）
Math.E 自然常数 e（约 2.71828）

术语说明：

  • LNx：lnx，自然对数（底数为自然常数 e）
  • LOGxE：logₓe，以 x 为底 e 的对数，与 LNx 互为倒数
  • SQRT：平方根；Math.SQRT1_2 代表(1/2)的平方根，下划线表示分数

2. 核心静态方法

取整类：

  • Math.ceil(x)：向上取整（取 ≥x 的最小整数）
  • Math.floor(x)：向下取整（取 ≤x 的最大整数）
  • Math.round(x)：四舍五入取整

基础运算：

  • Math.abs(x)：绝对值
  • Math.max(a, b, c...) / Math.min(a, b, c...)：取一组数最大/最小值
  • Math.pow(底数, 指数)：幂运算
  • Math.sqrt(x)：平方根
  • Math.log(x)：自然对数（以 e 为底）
  • Math.log10(x)：常用对数（以 10 为底）
  • Math.exp(x)：指数运算（e 的 x 次方）

随机数：

  • Math.random()：无参，返回 [0, 1) 之间随机小数

注意：除 Math.random() 外，其余方法必须传入数字参数

特性 sessionStorage localStorage
生命周期 会话级，关闭标签页清空 持久化，长期保存
数据共享 同标签页 同域名下所有页面

2. localStorage 核心 API

存入数据：setItem(key, value)

读取数据：getItem(key)

3. 关键规则
