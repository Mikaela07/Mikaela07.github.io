方法重载 & 重写

重载 Overload（同类）

口诀：同类、同名、不同参

在同一个类中，方法名相同，但参数的个数/类型/顺序不同，与返回值无关。

重写 Override（子类父类）

口诀：子类覆写父类方法

子类继承父类后，改写父类原有方法体。

重写规则（两同两小一大）：

规则 说明
两同 方法名、参数列表必须相同
两小 返回值更小/相等、抛出异常范围更小/相等
一大 访问权限更大/相等（public > protected > 默认）

抽象类

核心特点

特性 说明
关键字 abstract class
构造方法 有构造方法，供子类初始化使用
成员组成 可包含普通变量、普通方法、无实现体的抽象方法
继承规则 单继承，一个类只能继承一个抽象类

抽象方法

  • 使用 abstract 修饰的方法，没有方法体

  • 子类必须重写全部抽象方法，否则子类也需加 abstract

普通子类规则

  • 必须重写抽象父类的所有抽象方法

  • 如果不重写，则子类也需要加 abstract

接口

核心特点

特性 说明
关键字 interface
构造方法 无构造方法，不能直接实例化
内部变量 默认是常量（public static final），赋值后不可修改
实现规则 多实现，一个类可同时实现多个接口

实现类规则

  • 普通实现类必须重写接口所有抽象方法

  • 接口中方法默认 public abstract

Lambda 表达式

基本结构

三部分：

  • 参数变量：变量名可自定义，不是固定的

  • ->：语法符号

  • {}：语句块

Lambda 表达式在功能上等同于一个匿名方法，相当于把方法名和 public void 修饰符都省略了。

类型自动识别

大多数情况下，使用 Lambda 表达式的目的是让代码尽量简洁，所以尽量省略参数变量的类型，由系统根据上下文自动识别。

  • forEach() 是 Java 集合的循环遍历方法，每次循环时 f 指代当前遍历到的元素

  • 因为 fruits 类型是 List<Fruit>，集合元素类型是 Fruit，所以 f 的类型自动识别为 Fruit，可以直接调用 Fruit 类的方法

显式指定参数类型

如果代码比较复杂，为了易阅读、易维护，也可以为参数变量指定类型：

⚠ 注意：一旦指定了参数类型，即使只有一个参数，也必须使用小括号 () 包裹，否则会出错。

  • 省略类型时单参可省括号：f -> {} ✅

  • 指定类型时单参必须加括号：(Fruit f) -> {} ✅，Fruit f -> {} ❌

⚠ 注意：Lambda 表达式必须配合上下文、跟其他方法配合使用，不是一个独立语句，不能单独写 f -> {...}。

参数写法规则

情况 写法 括号要求
单参数（省略类型） f -> {} 括号可省
单参数（指定类型） (Fruit f) -> {} 必须加括号
多参数 (s1, s2) -> {} 必须加括号
无参数 () -> {} 必须加括号

语句块写法规则

单条语句：可以不加大括号 {}

多条语句：必须用大括号 {} 包裹

推荐：无论几条语句都加上大括号 {}，代码块边界更明确。

引用外部变量

Lambda 的语句块 {} 内部可以读取外部局部变量，但有两条约束。

规范一：引用的局部变量必须是最终变量

被引用的局部变量，即使不写 final 关键字，也要具备 final 特性：初始化之后不允许被修改。

❌ 错误场景 1：在 Lambda 表达式执行完之后，外部修改这个局部变量

❌ 错误场景 2：在 Lambda 表达式内部修改外部局部变量

✅ 允许的写法：外部只赋值一次，后续不再修改

报错提示：从lambda表达式引用的本地变量必须是最终变量或实际上的最终变量

规范二：Lambda 参数不能和外部局部变量同名

Lambda 的参数变量名，不允许和方法内的局部变量名字重复。

双冒号 :: 方法引用

Java 8 支持的双冒号 :: 语法，是 Lambda 表达式的简化写法，属于 Lambda 相关的重要特性。

  • 不能独立使用，必须配合 forEach、sort 等特定方法使用

  • 作用：直接引用已有的方法，替代单条执行语句的 Lambda，省略参数变量的书写

语法结构

组成 说明
左侧 类名（调用静态方法）或实例对象（调用非静态方法）
:: 语法符号
右侧 方法名，不需要写小括号 ()，也不需要传入参数

等价示例：System.out::println 完全等同于 n -> { System.out.println(n); }，系统会自动把遍历得到的元素按顺序作为参数传递给引用的方法。

四种用法

用法一：静态方法引用

格式：类名::静态方法名

用法二：非静态方法引用

格式：对象::非静态方法名

System.out::println 就属于非静态方法引用，System.out 本身就是一个实例对象。

用法三：多参数方法引用

多参数的 Lambda 同样可以用 :: 简化，系统会自动按参数顺序传递，和参数变量名无关。

用法四：父类方法引用

在子类中，使用 super::方法名 调用父类的非静态方法。

四种用法汇总

用法 格式 示例
静态方法引用 类名::静态方法名 LambdaTest::print
非静态方法引用 对象::非静态方法名 lt::print
多参数方法引用 类名::方法名 SortTest::compute
父类方法引用 super::方法名 super::print

Stream 流

1. 创建流的三种方式

接口中操作数据的方法通常叫作 API，Stream 流常见的创建方式有三种：

① 直接创建

通过 Stream.of() 直接传入元素创建。

② 由数组转化

通过 Stream.of(数组名) 将数组转为流。

两种方式本质一样，直接创建的方式底层就是字符串数组。

③ 由集合转化

调用集合的 .stream() 方法将集合转为流。

有序特性：源数据（集合或数组）的数据是有序的，流中的元素也是有序排队的。

2. 迭代流 forEach

Stream 提供了 forEach() 方法来遍历迭代流中的元素，和集合的 forEach 同名，支持 Lambda / 方法引用写法。

⚠ 注意：必须用泛型语法指定 Stream 中对象的类型，系统才能自动识别 Lambda 表达式的参数类型。

3. 注意事项

集合类的 forEach() 方法与流的 forEach() 方法无关，仅仅是方法名相同，不要混淆。

4. map() 数据映射

map() 方法通常称作映射，作用是用新的元素替换掉流中相同位置的元素，相当于流中每个对象都经历一次转换。
